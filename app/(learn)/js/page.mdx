# JavaScript Functions & Variables 🚀

<AnalogyCard title="What is a Variable?" emoji="📦" color="#F7DF1E">
  Imagine your mom's kitchen has jars with labels: **"سكر"** (sugar), **"ملح"** (salt), and **"أرز"** (rice). 
  Each jar holds something different. Variables are just labels for boxes that hold data!
</AnalogyCard>

### 1. Using `let` (The Normal Box) 📦

`let` is a regular box where you can change what's inside whenever you want!

<CodeBlock 
  fileName="toys.js"
  code={`let myToy = "كرة";
console.log(myToy); // Shows: كرة

// You can change it!
myToy = "عروسة";
console.log(myToy); // Shows: عروسة`} 
/>

### 2. Using `const` (The Locked Box) 🔒

`const` is like writing with a permanent marker—once it's there, it stays!

<CodeBlock 
  fileName="identity.js"
  code={`const myName = "Ahmed";
// myName = "Mohamed"; // ❌ ERROR: You can't rename Ahmed!`} 
/>

## What is a Function? 🎪

<AnalogyCard title="The Tea Recipe" emoji="🫖" color="#87ceeb">
  When you want tea, your mom doesn't "re-learn" how to make it. She follows a **recipe**: boil water, add tea, add sugar. 
  A function is a saved recipe you can use over and over!
</AnalogyCard>

### Example: The Koshari Calculator 🇪🇬

Let's combine variables and functions to see how much lunch costs!

<CodeBlock 
  fileName="koshari_shop.js"
  code={`function orderKoshari(size, addTomato) {
    let price = size === "large" ? 25 : 15;
    
    if (addTomato) {
        price = price + 3;
    }
    
    return "Your koshari costs " + price + " جنيه";
}

console.log(orderKoshari("large", true)); // 28 جنيه`} 
/>
