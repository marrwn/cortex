# 5. String Concatenation: Glueing Text Together 🧩

You can **combine text and numbers** using the `+` operator with strings.

<AnalogyCard title="Beads on a String" emoji="📿" color="#87CEEB">
  Think of each piece of text as a **bead**. The `+` operator is the **thread**
  that connects them together into one necklace. `"أحمد"` + `" "` + `"علي"` = `"أحمد علي"`
</AnalogyCard>

<CodeBlock
  fileName="concatenation.js"
  code={`// Combining strings
console.log("Hello" + " " + "World");  // Hello World
console.log("أهلاً" + " " + "يا" + " " + "صاحبي"); // أهلاً يا صاحبي

// Combining strings with numbers
console.log("Price: " + 25 + " LE");    // Price: 25 LE
console.log("Age: " + 20);              // Age: 20

// ⚠️ WATCH OUT — the order matters!
console.log(5 + 3 + " LE");     // "8 LE"  — math first, then string
console.log("Total: " + 5 + 3); // "Total: 53" — string mode, so 5 and 3 become text!
console.log("Total: " + (5 + 3)); // "Total: 8" — parentheses fix it!`}
/>

<CortexCallout type="warning">
  **The `+` Trap:** When `+` sees a string on either side, it switches to **"glue mode"**
  and treats everything as text. `"5" + 3` = `"53"` not `8`!
  Use **parentheses** around math to force calculation first: `"Total: " + (5 + 3)` = `"Total: 8"`.
</CortexCallout>
