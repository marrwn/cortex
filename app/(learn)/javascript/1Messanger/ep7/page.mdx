# 7. Putting It All Together: `console.table()` 📊

`console.table()` displays data in a beautiful table format. Perfect for organized output.

<CodeBlock
  fileName="tables.js"
  code={`// Array as a table
console.table(["Cairo", "Alexandria", "Luxor", "Aswan"]);

// Array of objects — the real power!
console.table([
  { city: "Cairo", population: "10M", famous: "Pyramids" },
  { city: "Alexandria", population: "5M", famous: "Library" },
  { city: "Luxor", population: "1.3M", famous: "Karnak Temple" }
]);

// Single object
console.table({
  name: "Koshary Abou Tarek",
  location: "Downtown Cairo",
  rating: 4.5,
  priceRange: "15-35 LE"
});`}
/>
