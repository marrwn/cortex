# Logging Multiple Things

You can print **multiple values** in one `console.log()` by separating them with commas.

<CodeBlock
  fileName="multiple-logs.js"
  code={`// Multiple values in one line
console.log("Name:", "Ahmed", "Age:", 25);
// Output: Name: Ahmed Age: 25

// Logging math results
console.log("5 + 3 =", 5 + 3);
// Output: 5 + 3 = 8

// Mixing text, numbers, and booleans
console.log("Koshari costs", 25, "LE", "- Delicious?", true);
// Output: Koshari costs 25 LE - Delicious? true`}
/>
