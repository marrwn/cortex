# 6. Multi-Line Output & Special Characters 📄

Sometimes you need to print **multiple lines** or include special characters.

<CodeBlock
  fileName="multiline.js"
  code={`// Method 1: Multiple console.log calls
console.log("Line 1");
console.log("Line 2");
console.log("Line 3");

// Method 2: The newline character \\n
console.log("Line 1\\nLine 2\\nLine 3");

// Method 3: Template literals (backticks) — BEST WAY
console.log(\`Line 1
Line 2
Line 3\`);

// Special characters
console.log("He said \\"Hello!\\"");    // He said "Hello!"
console.log("Tab\\there");              // Tab    here
console.log("Back\\\\slash");           // Back\slash

// Building a box
console.log("╔══════════════╗");
console.log("║  WELCOME!    ║");
console.log("╚══════════════╝");`}
/>
