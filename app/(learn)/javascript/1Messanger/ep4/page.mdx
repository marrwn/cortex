console.log(10 + 5);   // 15  — Addition
console.log(10 - 5);   // 5   — Subtraction
console.log(10 * 5);   // 50  — Multiplication
console.log(10 / 5);   // 2   — Division

// The remainder operator (%)
console.log(10 % 3);   // 1   — 10 ÷ 3 = 3 remainder 1
console.log(15 % 5);   // 0   — 15 ÷ 5 = 3 remainder 0 (divides evenly!)
console.log(7 % 2);    // 1   — 7 is odd (remainder 1)
console.log(8 % 2);    // 0   — 8 is even (remainder 0)

// Exponents (**)
console.log(2 ** 3);   // 8   — 2 × 2 × 2
console.log(5 ** 2);   // 25  — 5 × 5
console.log(10 ** 6);  // 1000000 — one million!

// Order of operations (PEMDAS / BODMAS)
console.log(2 + 3 * 4);     // 14  — multiplication first!
console.log((2 + 3) * 4);   // 20  — parentheses force addition first`}
/>

# Useful Trick: Remainder for Real Life

The `%` operator seems weird, but it's incredibly useful.

<CodeBlock
  fileName="remainder-tricks.js"
  code={`// Trick 1: Check if a number is EVEN or ODD
console.log(4 % 2);   // 0 → EVEN ✅
console.log(7 % 2);   // 1 → ODD
console.log(100 % 2); // 0 → EVEN ✅
console.log(33 % 2);  // 1 → ODD

// Trick 2: Get the last digit of any number
console.log(2025 % 10);  // 5  — last digit
console.log(187 % 10);   // 7  — last digit
console.log(40 % 10);    // 0  — last digit

// Trick 3: Check if a number divides evenly
console.log(15 % 5);  // 0 → 15 is divisible by 5 ✅
console.log(15 % 4);  // 3 → 15 is NOT divisible by 4
console.log(100 % 25); // 0 → divisible ✅`}
/>
