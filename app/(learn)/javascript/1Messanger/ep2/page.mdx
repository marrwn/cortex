# 2. Different Types of Messages 📊

`console.log()` isn't the only way to talk. JavaScript gives you **different voices** for different situations.

<div className="grid grid-cols-1 md:grid-cols-3 gap-6 my-8">
  <ConceptCard
    category="Normal"
    title="console.log()"
    description="Regular message. Like texting a friend. Use it for general output and debugging."
  />
  <ConceptCard
    category="Danger"
    title="console.error()"
    description="Error message (shows in red). Like a fire alarm 🚨. Use it when something goes WRONG."
  />
  <ConceptCard
    category="Caution"
    title="console.warn()"
    description="Warning message (shows in yellow). Like a yellow traffic light ⚠️. Something might be wrong."
  />
</div>

<CodeBlock
  fileName="message-types.js"
  code={`// Normal message — just information
console.log("Order received: 2x Koshari");

// Warning — something is off but not broken
console.warn("⚠️ Low stock: Only 3 Koshari bowls left!");

// Error — something is WRONG
console.error("❌ Payment failed! Card declined.");

// Table — display organized data beautifully
console.table(["Koshari", "Foul", "Taameya", "Molokhia"]);`}
/>
