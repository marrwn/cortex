## 3. Comments: Notes to Yourself 📝

Comments are lines that JavaScript **completely ignores**. They're notes for humans, not machines.

<AnalogyCard title="Sticky Notes on Your Code" emoji="📌" color="#FFD700">
  You know those yellow sticky notes your teacher puts on important pages? 
  Comments are the same — they help you (and others) understand **why** the code exists. 
  The computer skips right over them.
</AnalogyCard>

<CodeBlock
  fileName="comments.js"
  code={`// This is a single-line comment
// JavaScript ignores everything after //

console.log("This runs!"); // You can also comment after code

// console.log("This does NOT run — it's commented out!");

/*
  This is a multi-line comment.
  Everything between /* and */ is ignored.
  Use it for longer explanations.
  
  Like a recipe note:
  Step 1: Boil water
  Step 2: Add koshari noodles
  Step 3: Serve with sauce
*/

console.log("This also runs!");`}
/>

<CortexCallout type="warning">
  **When to use comments:**
  - ✅ Explain **WHY** you did something (not what — the code shows what)
  - ✅ Temporarily disable code for testing
  - ✅ Leave TODO notes: `// TODO: fix this later`
  - ❌ Don't comment obvious things like `// print hello` above `console.log("hello")`
</CortexCallout>
