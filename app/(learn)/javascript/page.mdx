## How Does JavaScript Actually Work? ⚙️

You don't need to fully understand this now, but here's the **big picture**:

<AnalogyCard title="The Restaurant Kitchen" emoji="👨‍🍳" color="#FFD700">
  Think of a restaurant:
  - The **customer** (User) looks at the menu and places an order
  - The **waiter** (Browser) takes the order to the kitchen
  - The **chef** (JavaScript Engine) reads the recipe and cooks the food
  - The **plate** (DOM) is how the food is presented back to the customer
  
  JavaScript is the **chef** — it reads your instructions (code) and makes things happen on screen.
</AnalogyCard>

## The JavaScript Mindset 🧠

Before you dive deeper, here are **5 truths** every JavaScript developer learns:

<div className="bg-[#E8F5E9] border-4 border-black p-8 rounded-[40px] my-12 shadow-[10px_10px_0px_0px_rgba(0,0,0,1)]">
  <h3 className="font-pixel text-2xl uppercase mb-6">The 5 Developer Truths 💡</h3>
  <p className="font-bold mb-4 text-sm">1. **Errors are normal.** Even senior developers with 20 years of experience get errors every day. An error is not failure — it's a clue.</p>
  <p className="font-bold mb-4 text-sm">2. **Google is your best friend.** Professional developers Google things constantly. "How to do X in JavaScript" is the most common search in tech.</p>

<Playground
  config={{

    mainFile: "/index.js",

      "/index.js": `/*
  🔮 DON'T PANIC — you're NOT supposed to understand this yet!
  Just run it and see what JavaScript can do.
  In a few chapters, you'll write code like this easily.

// A mini Egyptian restaurant ordering system
const menu = [
  { id: 1, name: "Koshari", price: 25, emoji: "🥣" },
  { id: 2, name: "Foul", price: 10, emoji: "🫘" },
  { id: 3, name: "Shawarma", price: 45, emoji: "🌯" },
  { id: 4, name: "Feteer", price: 35, emoji: "🥧" },
  { id: 5, name: "Molokhia", price: 30, emoji: "🥬" },
];

function displayMenu(items) {
  console.log("╔════════════════════════════════╗");
  console.log("║    🇪🇬 CAIRO BITES MENU 🇪🇬     ║");
  console.log("╚════════════════════════════════╝");
  items.forEach(item => {
    console.log(\` \${item.emoji} \${item.name.padEnd(12)} \${item.price} LE\`);
  });
  console.log("─".repeat(34));
}

function placeOrder(itemIds) {
  const ordered = itemIds.map(id => menu.find(m => m.id === id));
  const total = ordered.reduce((sum, item) => sum + item.price, 0);
  const tax = total * 0.14;
  
  console.log("\\n🧾 YOUR ORDER:");
  ordered.forEach(item => {
    console.log(\`   \${item.emoji} \${item.name} — \${item.price} LE\`);
  });
  console.log("─".repeat(34));
  console.log(\`   Subtotal: \${total} LE\`);
  console.log(\`   Tax (14%): \${tax.toFixed(1)} LE\`);
  console.log(\`   💰 TOTAL:  \${(total + tax).toFixed(1)} LE\`);
  console.log("\\n✅ Order confirmed! Enjoy your meal!");
}

displayMenu(menu);
placeOrder([1, 3, 5]); // Ordering Koshari, Shawarma, Molokhia

// 🎯 Try changing the order!
// Change [1, 3, 5] to different numbers (1-5) and re-run!`
    }
  }}
/>
