# 1. Your First Variable 📦

A variable is created in **three steps**:

<CodeBlock
  fileName="first-variable.js"
  code={`//  keyword   name      value
//    ↓        ↓          ↓
    let     myName  =  "Ahmed";
    
// Now "myName" is a jar labeled "myName" containing "Ahmed"
console.log(myName); // Ahmed`}
/>

That's it. **Keyword → Name → Value.** Let's break down each part.
